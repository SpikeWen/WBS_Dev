# MVP 验收清单

本文用于确认当前 WBS_Dev 是否已经达到“企业官网后台管理系统 / 模板建站系统”的最小可运行闭环。

## 主流程

- [x] 可以创建空壳官网。
- [x] 可以选择并持续维护已有站点。
- [x] 可以维护站点身份：站点名称、模板 ID、域名、前台名称、Logo、Favicon、默认 SEO。
- [x] 可以维护企业档案：企业名称、行业、简介、联系方式、地址、服务区域。
- [x] 可以维护固定页面，并控制页面状态、排序和是否显示在前台导航。
- [x] 可以维护文章、产品、案例、服务、FAQ。
- [x] 可以上传媒体素材，并在 Logo、Favicon 和核心封面图字段中直接选择已上传图片。
- [x] 保存后台内容后，前台预览会读取最新内容。
- [x] 可以预览首页、固定页面和文章/产品/案例/服务详情页。
- [x] 可以发布静态 HTML，并保留发布记录。

## 数据与接口

- [x] 后端使用 FastAPI。
- [x] 数据持久化使用 SQLite。
- [x] 站点、资料、页面、文章、产品、FAQ、案例、服务、媒体、发布记录均有基础持久化。
- [x] 路由层只做请求编排和响应转换。
- [x] 应用层统一编排站点内容。
- [x] 前台预览渲染已放在基础设施层。
- [x] 重复 slug 会返回明确的业务冲突提示。
- [x] 发布前检查是非强制提示，不阻塞主流程。

## 前端后台

- [x] React + TypeScript + Vite 构建通过。
- [x] 前端已有站点驾驶舱。
- [x] 主要编辑区已按面板拆分。
- [x] 表单保存前有关键字段校验。
- [x] API 错误提示已做基础友好化。
- [x] 保存内容后会同步刷新预览和发布前检查摘要。

## 当前不纳入 MVP 的增强项

- 用户登录、角色权限、操作审计。
- 多租户/代理商/计费系统。
- 复杂拖拽建站和多端系统。
- 模板主题配置、首页区块编排、复杂导航树。
- 内容检索、分页、批量操作。
- 图片裁剪、素材分类、引用关系分析。
- 发布回滚、发布差异对比。
- AWA 自动诊断插件。

这些能力可以在 MVP 稳定后逐步加入，但不应反向阻塞当前官网后台主流程。
