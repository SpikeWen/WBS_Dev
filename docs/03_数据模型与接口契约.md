# 数据模型与接口契约

## 1. 核心实体

### 1.1 Site

站点主实体，代表一个客户站点。

字段建议：

- id
- tenant_id
- name
- template_id
- domain
- status
- created_at
- updated_at

### 1.2 SiteProfile

站点基础信息。

字段建议：

- site_id
- site_name
- subtitle
- logo
- favicon
- default_title
- default_description

### 1.3 CompanyProfile

企业信息。

字段建议：

- site_id
- company_name
- legal_name
- industry
- description
- phone
- email
- address
- service_area

### 1.4 ContentItem

内容条目。

字段建议：

- id
- site_id
- content_type
- title
- slug
- summary
- body_json
- body_html
- status

### 1.5 MediaAsset

素材资源。

字段建议：

- id
- site_id
- filename
- url
- alt_text
- file_type
- size

### 1.6 PublishRecord

发布记录。

字段建议：

- id
- site_id
- version
- status
- preview_url
- publish_url
- created_at

### 1.7 AuditRecord

AWA 诊断记录。

字段建议：

- id
- site_id
- awa_run_id
- score
- report_path
- result_path
- issues_json

## 2. 接口契约原则

- 所有接口返回统一格式。
- 所有写接口必须返回操作结果和可追踪 id。
- 所有状态变更都要可回滚。
- 所有发布动作都要可复查。

## 3. 接口分组

### 3.1 站点接口

- 创建站点
- 更新站点信息
- 查询站点详情
- 获取站点状态

### 3.2 内容接口

- 新增内容
- 编辑内容
- 发布内容
- 下线内容
- 获取内容列表

### 3.3 素材接口

- 上传素材
- 维护 alt
- 删除素材
- 查询素材使用情况

### 3.4 发布接口

- 生成预览
- 执行发布
- 回滚版本
- 生成 sitemap / robots

### 3.5 诊断接口

- 触发可选 AWA 诊断
- 查询诊断结果
- 获取优化建议

## 4. 返回格式建议

```json
{
  "success": true,
  "data": {},
  "error": null,
  "request_id": "req_xxx"
}
```

## 5. 关键约束

- 不允许前端直接拼装最终发布结构。
- 不允许发布接口绕过内容审核。
- 不允许 AWA 结果只展示分数不展示问题。
- 不允许把诊断能力写成主流程强制门禁。
- 不允许内容缺失时伪造字段值。
