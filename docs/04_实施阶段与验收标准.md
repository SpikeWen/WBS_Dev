# 实施阶段与验收标准

## 1. Phase 0

目标：跑通独立版骨架。

完成项：

- 站点创建
- 站点身份
- 企业档案
- 预览框架
- 固定模板骨架

验收标准：

- 能创建一个站点。
- 能看到空壳前台。
- 能保存基础信息。

## 2. Phase 1

目标：完成内容中枢。

完成项：

- 固定页面
- 资讯文章
- 产品资料
- 项目案例
- 发展节点
- 资质荣誉
- 服务项目
- 问答知识库

验收标准：

- 内容可增删改查。
- 修改后前台同步更新。
- 内容状态可追踪。

## 3. Phase 2

目标：完成运营组件库和工具扩展台。

完成项：

- 展示位
- 轮播
- 外链
- 留言
- 内容关联链
- 表单构建器
- 素材体检
- 媒体资产库
- 站内检索维护

验收标准：

- 组件可配置。
- 素材可复用。
- 留言可查看。

## 4. Phase 3

目标：增加可选诊断能力，不干扰主流程。

完成项：

- 预览构建
- 正式发布
- sitemap / robots
- 可选 AWA 联动
- 诊断报告展示
- 诊断开关配置

验收标准：

- 发布后前台可访问。
- AWA 结果可回写后台。
- 未开启诊断时系统仍可完整运行。
- 开启诊断时只做提示，不强制阻止正常站点发布。

## 5. Phase 4

目标：做稳定性和扩展能力。

完成项：

- 回滚
- 日志追踪
- 版本对比
- 接口扩展
- 存储替换

验收标准：

- 可按版本恢复。
- 可定位问题来源。
- 可替换实现而不改核心业务。
